# Рабочий процесс BoneQC

## Назначение

BoneQC выполняет автоматический технический контроль качества DXA-исследований до дальнейшей врачебной интерпретации.

Автоматический результат является QC-оценкой и не является диагнозом.

## Участники процесса

### Оператор

Оператор:

- загружает исследование;
- запускает автоматический анализ;
- просматривает технический результат.

### Frozen C7 Runtime

C7 выполняет автоматическую оценку поддерживаемых нарушений качества.

### Врач-эксперт

Эксперт может независимо оценить исследование и сохранить собственную разметку.

Экспертная оценка хранится отдельно от результата C7.

## Общая схема

~~~text
DICOM
  ↓
проверка и деидентификация
  ↓
автоматический C7 QC
  ↓
PASS / FAIL / CANNOT_ASSESS
  ↓
при необходимости экспертная проверка
~~~

## Поддерживаемые области

BoneQC обрабатывает:

~~~text
SPINE
LEFT_HIP
RIGHT_HIP
~~~

## Контроль позвоночника

Для позвоночника проверяются:

- корректность укладки;
- отклонение оси;
- наличие посторонних объектов и выраженных артефактов.

Контроль оси использует зафиксированный геометрический критерий.

## Контроль бедра

Для проксимального отдела бедренной кости проверяются:

- укладка;
- ротация;
- область интереса;
- поле обзора.

## PASS

~~~text
quality_class = 0
~~~

PASS означает, что frozen C7 не выявил поддерживаемого нарушения технического качества.

PASS не означает:

- отсутствие заболевания;
- нормальную минеральную плотность костной ткани;
- отсутствие остеопороза;
- окончательное врачебное заключение.

## FAIL

~~~text
quality_class = 1
~~~

FAIL означает, что C7 выявил одно или несколько поддерживаемых нарушений технического качества.

Поле `violation_type` содержит выявленный тип или типы нарушений.

## Несколько нарушений

Одно исследование может содержать несколько нарушений одновременно.

BoneQC сохраняет общий результат QC и список обнаруженных нарушений.

## CANNOT_ASSESS

Если автоматическая оценка невозможна, исследование не должно автоматически считаться качественным.

В таких случаях используется состояние `CANNOT_ASSESS`.

Причинами могут быть:

- неподдерживаемая анатомическая область;
- некорректный входной файл;
- невозможность безопасной обработки.

## quality_prob

`quality_prob` — непрерывный QC score frozen C7.

Он не является:

- accuracy модели;
- процентом качества исследования;
- вероятностью диагноза;
- вероятностью того, что модель «права»;
- заявленной клинически откалиброванной вероятностью.

Итоговый `quality_class` нельзя пересчитывать простым правилом `quality_prob >= 0.5`.

## BoneQC Expert

Экспертный контур предназначен для независимой оценки человеком.

Эксперт может:

- определить качество исследования;
- указать тип нарушения;
- выполнить геометрическую разметку;
- оставить комментарий;
- отметить невозможность оценки.

## Blind expert workflow

Для независимого сравнения эксперт может сначала сохранить собственную оценку и только после этого увидеть автоматический результат.

Это уменьшает влияние ответа модели на первоначальное мнение эксперта.

## Разделение результатов

Автоматический результат C7 и экспертная оценка являются разными сущностями.

Экспертная разметка:

- не меняет frozen C7;
- не изменяет его thresholds;
- не приводит к автоматическому переобучению модели.

## Human-in-the-loop

Если исследование не может быть уверенно обработано автоматическим контуром, дальнейшая оценка должна быть передана человеку.

## Ограничения

BoneQC:

- поддерживает только заявленные анатомические области;
- зависит от качества исходного DICOM;
- выполняет технический QC;
- не выполняет диагностику;
- не заменяет медицинское решение врача.
